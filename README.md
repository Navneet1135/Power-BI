# 📊 Business Performance & Sales Analysis Dashboard (Power BI)

## 🚀 Project Overview

This project showcases a **comprehensive multi-page Power BI dashboard** built to analyze and monitor business performance using sales data from **2023 and 2024**.

The dashboard provides deep insights into:

* Sales performance 📈
* Customer behavior 👥
* Product trends 🛍️
* Regional distribution 🌍
* KPI tracking vs targets 🎯

It is designed for **business stakeholders, analysts, and decision-makers** to interactively explore data and derive actionable insights.

## 🛠️ Tools & Technologies

* **Power BI Desktop (.pbix)** – Dashboard development
* **DAX (Data Analysis Expressions)** – KPI calculations
* **Power Query** – Data cleaning & transformation
* **Python (Jupyter Notebook)** – Data preprocessing
* **CSV Datasets (2023 & 2024)**

---

## 🔄 Data Workflow

1. Data imported from CSV files (2023 & 2024)
2. Data cleaned and transformed using Power Query
3. Data model created with relationships
4. KPIs calculated using DAX
5. Interactive visuals designed across multiple pages
